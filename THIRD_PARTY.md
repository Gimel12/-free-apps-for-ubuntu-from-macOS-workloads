# Third-party dependencies

The application code in this repository is MIT licensed. Dependencies are installed separately and retain their own licenses; their source and binary packages are not vendored here.

| Dependency | Used for | Project |
| --- | --- | --- |
| Python | Runtime and SQLite interface | https://www.python.org/ |
| PySide6 / Qt | Notes desktop interface | https://doc.qt.io/qtforpython-6/ |
| Pygments | Code syntax highlighting | https://pygments.org/ |
| PyGObject / GTK 3 | Snippets desktop interface | https://pygobject.gnome.org/ |
| AutoKey | X11 abbreviation and shortcut service | https://github.com/autokey/autokey |
| xdotool | X11 window focus and paste integration | https://github.com/jordansissel/xdotool |

The installer uses Ubuntu packages and PyPI distributions. Refer to those packages for the applicable licenses and notices. macOS product names identify familiar workflows and do not imply endorsement or compatibility with every feature.

Additional dependencies for the optional components:

| Dependency | Used for | Project |

Caffeine, Blur My Shell and Rounded Window Corners Reborn are separate third-party
extensions, not authored or redistributed by this repository. Install compatible
versions through GNOME Extensions. This repository does not contain game files,
proprietary application installers, personal launcher shortcuts or user databases.
