# Clock at Top Left

GNOME Shell 46: places the date/calendar after the workspace indicator.
When the center box is empty, the right tray can use the width remaining after
the left box, instead of being restricted to half of the screen. Portrait
orientation uses 8px natural / 4px minimum horizontal button padding.
The native allocation remains in use if another extension populates the center.
All overrides, CSS classes, and the original clock position are restored on disable.
